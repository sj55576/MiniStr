# MiniStr

ブラウザで遊べるターン制戦略ゲームです。Issue #1 の Phase 2–4 を実装しています。

🎮 **[GitHub Pages でプレイする](https://sj55576.github.io/MiniStr/)** | 📚 [実装仕様](#実装仕様) | 🛠️ [セットアップ](#セットアップ)

## 概要

MiniStr は、複雑な地政学的シミュレーションをシンプルに体験できるターン制戦略ゲームです。プレイヤーはユニットを配置・移動・攻撃し、敵勢力を打ち破りマップを占領することを目指します。

### 主な特徴

- **リアルな戦場シミュレーション**：地形、霧、燃料、弾薬などのシステムで、戦術的な奥深さを実現
- **複数のユニットタイプ**：歩兵、戦車、航空機、艦船など多様なユニットで戦略の幅が広がる
- **AI対戦**：難易度設定可能な CPU オポーネント
- **複数マップ**：様々なステージで異なる戦況を体験
- **戦闘予測システム**：攻撃前に結果を予測可能
- **経済と占領システム**：施設占領による資源管理と経済戦略

## 操作方法

### ゲーム画面

1. **ユニット選択**：マップ上のユニットをクリックして選択
2. **移動**：ユニットを選択後、移動可能な範囲（黄色い枠）をクリック
3. **攻撃**：攻撃可能な敵ユニット（赤い枠）をクリック
4. **詳細表示**：ユニットをクリックして詳細情報を確認
5. **施設占領**：敵施設上に移動してターンを終了すると自動占領

### ターンシステム

- 各ターン、すべての味方ユニットを操作可能
- 「ターン終了」ボタンで敵ターンへ移行
- 敵 AI が自動で行動
- 勝利条件：敵全滅または敵施設の占領

### 画面要素

- **マップ表示**：地形、ユニット、施設の配置
- **ユニットステータス**：HP、燃料、弾薬、移動力
- **ゲームログ**：戦闘結果や重要なイベント

## 実装仕様

### アーキテクチャ

```
src/
├── game/           # ゲーム本体のロジック
│   ├── types.ts    # ゲーム状態の型定義
│   ├── state.ts    # ゲーム状態の管理
│   ├── commands.ts # ユーザーコマンド処理
│   ├── units.ts    # ユニットシステム
│   ├── terrain.ts  # 地形システム
│   ├── combat.ts   # 戦闘ロジック
│   ├── fog.ts      # 霧システム
│   ├── maps.ts     # マップデータ
│   └── index.ts    # ゲームの初期化
├── ai/             # AI実装
│   ├── rules.ts    # AI 決定ルール
│   └── index.ts    # AI エンジン
├── main.ts         # UI とのインテグレーション
└── ...test.ts      # ユニットテスト
```

### 主要システム

#### 1. ユニットシステム
- 複数のユニットタイプ（歩兵、戦車、航空機、艦船など）
- 各ユニットは HP、移動力、攻撃力、防御力を持つ
- 燃料と弾薬による制限

#### 2. 地形システム
- 複数の地形タイプ（平地、山地、水域など）
- 地形による移動コストと防御ボーナスの計算
- ユニットタイプによる移動可能性の判定

#### 3. 霧システム
- ユニットの視界範囲外は敵を認識できない
- リアルな戦術の深さを提供

#### 4. 戦闘システム
- 攻撃前に結果を予測
- HP に基づくダメージ計算
- 地形と防御力による軽減

#### 5. AI システム
- 複数の難易度設定
- ルールベースの AI 決定エンジン
- 戦術的な目標設定と実行

#### 6. 経済・占領システム
- 施設占領による資源獲得
- 施設の管理と資源管理

### 技術スタック

- **言語**：TypeScript
- **ビルド**：Vite
- **テスト**：Vitest
- **デプロイ**：GitHub Pages（自動）

## セットアップ

### 前提条件

- Node.js 22 以上
- npm 10 以上

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/sj55576/MiniStr.git
cd MiniStr

# 依存関係をインストール
npm install
```

### 開発

```bash
# 開発サーバーを起動（http://localhost:5173）
npm run dev

# テストを実行
npm test

# テストを監視モードで実行
npm run test:watch

# 本番ビルド
npm run build

# ビルド結果をプレビュー
npm run preview
```

### デプロイ

main ブランチへの push で自動的に GitHub Pages に デプロイされます。

## ゲーム進行フロー

1. **ゲーム開始**：マップと難易度を選択
2. **初期配置**：ユニット配置フェーズ
3. **プレイ**：ターン制で交互に行動
   - 味方ターン：ユニットを操作
   - 敵ターン：CPU が自動操作
4. **勝利/敗北**：勝利条件達成またはユニット全滅でゲーム終了
