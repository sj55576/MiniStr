## セッション URL を含む履歴の扱い

過去のコミットメッセージと pull request 本文に、認証情報そのものではない Claude セッション URL が残っています。これらは今後追加しないよう、寄稿ガイドと PR テンプレートで禁止します。

- PR 本文は編集して URL を除去できます。
- コミットメッセージの除去は既存履歴の書き換えと `main` の強制更新を伴うため、共同作業者への告知・clone の更新手順・バックアップを含む保守作業として別途実施します。
- 履歴を書き換えた場合は、すべてのブランチとタグを対象に URL の再検索を行ってください。

このため、セッション URL を完全に除去することを公開条件とする場合は、履歴浄化が完了するまで公開設定の変更を保留します。
